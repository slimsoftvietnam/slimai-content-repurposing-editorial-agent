# Brand voice setup and use

## Using an existing profile

Read the profile and follow its audience, purpose, voice traits, vocabulary, examples, preferred CTA, and prohibited language. Check whether it is a draft or approved. If the profile conflicts with the source's facts, keep the facts and flag the conflict; brand voice never licenses unsupported claims.

## Creating a profile

When asked to create or customize a voice profile:

1. Prefer first-party examples: approved website pages, posts, newsletters, sales material, and explicit brand-owner answers. Do not silently use a competitor or reference account as the brand's own evidence.
2. Analyze a balanced set of examples and note the source/sample for each observation. Separate directly observed traits from hypotheses. When the sample is small or inconsistent, state the uncertainty and ask only the questions needed to resolve it.
3. Describe practical dimensions such as audience, purpose, formality, warmth, energy, sentence rhythm, humor, technical depth, point of view, vocabulary, CTA style, and language to avoid. These dimensions are a working checklist, not fixed brand categories.
4. Include short examples of “sounds like / avoid” based on the supplied material, a checklist for writers, and unresolved questions. Do not present generated examples as historical brand copy.
5. Save the new profile under a separate, clearly named path (for example `content/brand-voice-demo-moc.md`). Mark it `DRAFT — needs brand-owner approval` until explicitly approved.
6. Keep demo brands and campaign-specific voice notes separate from the root `brand_voice.md`. Never replace or approve the SlimAI profile on the user's behalf.

For reference, Mailchimp's voice guide distinguishes stable voice from context-dependent tone, and Nielsen Norman Group describes tone across dimensions such as funny/serious, formal/casual, respectful/irreverent, and enthusiastic/matter-of-fact. Use these as analysis aids, not as a substitute for the brand's own examples: [Mailchimp style guide](https://styleguide.mailchimp.com/voice-and-tone/), [Nielsen Norman Group tone dimensions](https://www.nngroup.com/articles/tone-of-voice-dimensions/).
