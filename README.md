# SlimAI Content Repurposing Editorial Agent

Codex skill for turning source material into brand-voice SEO articles, Facebook and LinkedIn posts, TikTok scripts, visual assets, and a publish-ready 7-day editorial calendar.

## Install

Copy this directory into either:

- `<workspace>/.agents/skills/content-repurposing-editorial-agent/` for a project skill, or
- `~/.codex/skills/content-repurposing-editorial-agent/` for a personal skill.

The skill expects a workspace-level `brand_voice.md` and, when applicable, `content_calendar.csv`. See `SKILL.md` and `references/` for workflow details.

## Included resources

- `assets/blog-style-reference.png` — SlimAI blog art direction reference.
- `assets/logo-slimai.png` — exact brand mark used as an image layer.
- `references/` — editorial, brand voice, quality, publishing, and workbook guidance.
